## 2026-09-18 - Localized ARIA Labels for Icon-Only Buttons
**Learning:** This application uses Portuguese (pt-BR) as its primary language but contained several icon-only buttons (like modals' &times;, quick action buttons, and delete buttons) without accessible names. Adding `aria-label`s without localization creates a jarring experience for screen readers. Since the custom `applyI18n()` function overwrites the `textContent` of elements with `data-i18n` (which would break icon-only buttons), the accessible names must be hardcoded in Portuguese directly in the attributes.
**Action:** When adding `aria-label`s to HTML elements in this app, always use Portuguese (e.g., `aria-label="Fechar"` instead of "Close") to match the UI language and avoid WCAG violations, and avoid using `data-i18n` on buttons containing HTML icons.
