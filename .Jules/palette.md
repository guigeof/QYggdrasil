## 2024-05-18 - Handling Icon-Only Button Accessibility with Dynamic Localization
**Learning:** Found a pattern where `data-i18n` attributes on icon-only buttons (like modal close `&times;` buttons) overwrite the inner HTML/icon content entirely when localized (e.g. `el.textContent = trans` replaces the icon). This causes accessibility issues since these icon-only buttons lack `aria-label`s, but adding standard `data-i18n` breaks their visual display.
**Action:** For localized icon-only buttons in apps with this type of translation script, avoid `data-i18n` entirely on the button element. Instead, manually add hardcoded `aria-label` and `title` attributes in the application's primary UI language (in this case, Portuguese) to satisfy accessibility (WCAG) without risking icon destruction.
