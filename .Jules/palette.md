## 2024-05-18 - Localized ARIA Labels for Icon-Only Buttons
**Learning:** Adding `aria-label`s to UI elements like modal close buttons (`&times;`), list item remove buttons (`✕`), pagination controls (`‹`, `›`), and other icon-only buttons is crucial, as they otherwise get announced confusingly by screen readers (e.g., "times" or "multiplication"). In a multilingual/localized application (like pt-BR default), it is critical to write these labels directly in the local language when the dynamic translation engine (`data-i18n`) cannot be safely applied to elements with inner nodes or icons.
**Action:** When implementing icon-only buttons, always apply localized `aria-label` properties. Avoid using the custom `data-i18n` on elements where text replacement overrides inner icons.
