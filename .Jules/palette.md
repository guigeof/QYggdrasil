## 2024-11-28 - Native Portuguese aria-label Definitions for Icon-Only Buttons
**Learning:** Adding localization to icon-only buttons via the `data-i18n` attribute is problematic when the custom translation function uses `.textContent`. Using `textContent` overwrites any child elements within the button (e.g., SVG icons or HTML entities like `&times;` or `🗑`), destroying the visual icon. Moreover, since this app is in Portuguese by default, `aria-label`s must be explicitly defined in Portuguese to ensure proper screen reader pronunciation and compliance.
**Action:** When adding accessibility labels to icon-only HTML buttons in this repository, define the `aria-label` attribute natively in Portuguese (e.g., `aria-label="Fechar"`, `aria-label="Excluir workspace"`) instead of relying on `data-i18n`, to preserve the visual icons while achieving accessibility compliance.
