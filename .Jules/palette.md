## 2024-09-03 - Added ARIA labels to icon-only buttons
**Learning:** Icon-only buttons in this application must use hardcoded Portuguese (PT-BR) `aria-label` attributes instead of relying on the custom `data-i18n` translation implementation. The custom `applyI18n()` translation function in `web/js/app.js` replaces the `textContent` of elements containing the `data-i18n` attribute. If used on icon-only HTML buttons, it will overwrite and replace the inner icon elements (such as `&times;` or inline SVGs) with the translated text, breaking the layout.
**Action:** When adding accessibility labels to icon-only interactive elements in the future, hardcode the PT-BR string directly into the `aria-label` attribute (e.g., `aria-label="Fechar"`) and avoid using `data-i18n` on the parent node.
