## 2025-05-18 - Missing ARIA Labels on Icon-Only Buttons
**Learning:** Icon-only buttons (using SVG or emoji) fail accessibility checks if they lack an `aria-label` attribute, as screen readers cannot interpret their purpose. When modifying an internationalized application (e.g., pt-BR), it is critical that newly added ARIA labels are also localized so that visually impaired users receive instructions in the correct language. Furthermore, when using data attributes like `data-i18n` that replace `textContent` (as seen in `web/js/app.js`), applying it to icon-only buttons will overwrite the icon element entirely. The safest pattern here is to manually apply localized text to the `aria-label` attribute directly.
**Action:** When adding or fixing icon-only buttons, always check the app's primary language and ensure the `aria-label` text matches it. Additionally, review custom translation functions to ensure they do not inadvertently overwrite nested DOM structures like SVGs when applying translations.
